How It Works

All data stays on your device

Kid Tasker is fully self-contained. Your task lists, quiz settings, parental PIN, quiz history, and daily progress are stored in Android's private app storage on the device itself. This data is never sent over a network, never synced to an external server, and is never accessible to anyone other than the device owner.

The app has no accounts, no login, and no backend. There is no server receiving anything from your installation.

When you uninstall Kid Tasker, Android automatically deletes all locally stored data.

Permissions

Why the app requests an Accessibility Service permission

Kid Tasker uses Android's Accessibility Service to monitor which app is currently in the foreground. This is the standard Android mechanism for parental-control apps to detect when a child opens a different app and redirect them back.

This permission is used for one purpose only: keeping the device in supervised mode until daily tasks are complete. It is never used to:

  • Read the content of any app, message, or notification
  • Record keystrokes or screen activity
  • Transmit any information off the device

No other sensitive permissions — microphone, camera, location, contacts, or external storage — are requested or used.

Children's Privacy

Designed for children. Collecting nothing from them.

Kid Tasker is intended to be set up and managed by a parent or guardian, and used daily by a child. Because the app collects no information whatsoever, children's privacy is protected by design rather than by policy.

The app does not:

  • Collect personal information from children or adults
  • Display third-party advertising
  • Include social features, user profiles, or chat
  • Link to external websites
  • Communicate over the internet in any way

Kid Tasker complies with the Children's Online Privacy Protection Act (COPPA). Since no data is collected, there is nothing for parents to review, correct, or request deletion of — but if you have questions, the contact information below is available.

Third-Party Libraries

Open-source libraries used in the app

Kid Tasker includes the following open-source libraries. None of them collect data, phone home, or have network functionality:

  • Gson (Google) — reads local JSON files stored on-device
  • AndroidX (Google) — standard Android UI framework components
  • Material Components for Android (Google) — UI design system

None of these libraries transmit data or have access to any personal information.
